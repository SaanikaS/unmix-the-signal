# Clean source audio

Place your N clean source recordings here as `.wav` files (mono or stereo).

- Use one source per category if you can: speech, music, ambient.
- Use public-domain, CC0, CC-BY, or your own recordings. Credit any CC-BY sources in the main README.
- Each file should be at least as long as `--duration` (default 10 s).
- Filenames are sorted alphabetically; the first N files are used.

These files are git-ignored by default. Keep them locally and link to their origins in the main README.
